# OpenAPI

## 简介

[OpenAPI规范](https://spec.openapis.org/oas/latest.html)（**OpenAPI Specification, OAS**）为HTTP API定义了一套标准的、编程语言无关的接口描述，它允许人类和计算机在无需访问源代码、额外文档或检查网络流量的情况下发现并理解服务的功能。

当前最新版本为`3.2.0`。

## 格式

OpenAPI文档是一个JSON对象，可以使用JSON或YAML编写。

OAS对象有两种类型的字段：**固定字段**(fixed fields)和**模式字段**(patterned fields)。
