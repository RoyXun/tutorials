# 存储
默认情况下，在容器中创建的所有文件都存储在位于只读、不可变的镜像层之上的可写容器层中。当容器被销毁时，写入容器层的数据不会保留。每个容器的可写层都是唯一的，很难将数据从可写层提取到主机或另一个容器。

Docker支持以下几种类型挂载方式，可以用于容器数据持久化：
- [**卷挂载**](./volume)：卷是由Docker守护进程管理的数据持久化机制，即使容器被删除，卷中的数据也会保留。卷数据虽然存储在主机的文件系统上，但需要将卷挂载到容器中才能与卷中的数据交互。不支持直接访问卷数据。
- [**绑定挂载**](./bind)：绑定挂载是在主机系统路径和容器间创建直接连接，允许访问存储在主机上任意位置的文件或目录。由于它们没有被Docker隔离，因此主机上的非Docker进程和容器进程可以同时修改挂载的文件。
- [**tmpfs挂载**](./tmpfs)：tmpfs挂载将文件直接存储在主机内存中，确保数据不会写入磁盘。当容器停止或重启时数据会丢失。适用于需要临时内存存储的场景。
