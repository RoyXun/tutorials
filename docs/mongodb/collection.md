# 集合

集合（collection）是一组MongoDB文档（document）, 类似于关系型数据库的表。集合不需要有固定的模式，集合中的文档可以有不同的字段。

## 集合限制

集合名字可以下划线`_`或字母开头，但是满足以下条件：

- 不能包含`$`
- 不能是空字符串`""`
- 不能包含空字符`\0`
- 不能以`system.`前缀开头（用作内部使用）
- 不能包含`.system.`
- 命名空间（包含数据库名称、`.` 分隔符和集合/视图名称，`<database>.<collection>`）长度不超过：
  - 未分片集合和视图：255字节
  - 分片集合: 235字节
