# 数据库

数据库 (database) 是集合 (collection) 的容器。每个MongoDB服务器可以建立多个数据库，每个数据库都有自己的集合与权限。

## 限制

数据库名可以是满足以下条件的任意UTF-8字符串：

- 不能为空字符串`""`
- 不能包含以下字符：
  - Windows：`/\."$*<>:|?` 和空字符`\0`
  - Unix/Linux：`/\."$` 和空字符`\0`
- 长度不超过64字节

此外，有一些数据库名是系统保留的：

- `admin`: 存储管理信息，比如用户、角色、权限等；
- `local`: 存储复制集或分片集群的本地信息（不会被复制）。
- `config`: 分片集群相关配置；

系统默认提供`test` 普通数据库。
